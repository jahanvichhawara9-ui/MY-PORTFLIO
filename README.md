# 🌐 Jahanvi Chhawara — Personal Portfolio

A modern, responsive personal portfolio website created for **Jahanvi Chhawara**, a BCA student interested in web development, programming, and technology.

## 📌 About the Project

This portfolio website presents Jahanvi's academic background, technical skills, soft skills, hobbies, and contact information in a clean and professional web interface.

The website is designed to provide a simple online professional profile and showcase career interests in the IT field.

## ✨ Features

- Responsive and mobile-friendly design
- Fixed navigation bar with smooth scrolling
- Professional hero/home section
- About Me section
- Technical Skills section
- Soft Skills section
- Hobbies section
- Education section
- Contact section
- Interactive hover effects
- Active navigation effect while scrolling
- Clean modern UI with gradient styling

## 🛠️ Technologies Used

- **HTML5** — Website structure and content
- **CSS3** — Styling, layout, responsiveness, animations and hover effects
- **JavaScript** — Scroll-based active navigation functionality

## 🚀 How to Run the Project

1. Download or clone this project.
2. Open the project folder.
3. Double-click `index.html`.
4. The portfolio will open in your web browser.

### Using VS Code

1. Open the project folder in **Visual Studio Code**.
2. Open `index.html`.
3. Use **Live Server** if installed.
4. View the website in your browser.
